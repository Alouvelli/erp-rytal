    Structure du fichier Excel

    Chaque fichier correspond à un seul EC — même format que le modèle téléchargeable depuis la page Examens & Concours.

    Modèle anonyme (bouton violet) : mêmes colonnes, mais les colonnes Nom/Prénom sont remplacées par un pseudonyme (« ÉTUDIANT 001 », « ÉTUDIANT 002 »…) pour que l'enseignant saisisse les notes sans savoir de quel étudiant il s'agit. La colonne Matricule reste inchangée : à l'import, la correspondance avec le bon étudiant se fait automatiquement via le matricule, exactement comme pour le modèle nominatif.

    Format accepté : .xlsx uniquement. Utilisez le modèle téléchargé depuis le panneau de gauche.
    Procédure d'import
    1. Dans le panneau gauche, choisissez la classe et le semestre.
    2. Cliquez sur Charger la liste des ECs.
    3. Pour chaque EC, cliquez sur Excel pour télécharger son modèle pré-rempli.
    4. Ouvrez le fichier .xlsx dans Excel et saisissez les notes Devoir 1, Devoir 2, TP et Examen dans les cellules en jaune.
    5. Enregistrez le fichier sans changer le format (.xlsx).
    6. Dans le formulaire ci-dessus, sélectionnez la classe, le semestre, puis le fichier Excel complété.
    7. Cliquez sur Importer les notes. L'EC est identifié automatiquement via la colonne Code EC.
    8. Répétez les étapes 3 à 7 pour chaque EC.
